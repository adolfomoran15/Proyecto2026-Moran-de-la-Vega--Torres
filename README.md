## Descripción del proyecto

**Sopa, Sándwich o Ensalada** es un recetario web que te permite calcular la cantidad de ingredientes según los comensales y filtrar recetas por categoría, ingrediente y tiempo de preparación.

## Tecnologías utilizadas

- HTML5
- CSS3
- JavaScript

### Fuentes

- [Google Fonts](https://fonts.google.com/)

## Funcionalidades

| Funcionalidad             | Descripción                                               |
| ------------------------- | --------------------------------------------------------- |
| Catálogo de recetas       | Listado filtrable por categoría, ingredientes y tiempo    |
| Calculadora de porciones  | Recalcula las cantidades de ingredientes según comensales |
| Checklist de ingredientes | Permite tildar ingredientes ya usados                     |
